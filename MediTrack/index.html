About MediTrack

Hospital Emergency Bed Availability System

Project Introduction

MediTrack is a basic hospital bed availability tracking system designed to display information about hospitals and different categories of beds. It helps users view sample availability records in one place.

Project Objectives

• Display hospital information in an organized way.
• Show General, Oxygen, ICU and Ventilator bed records.
• Provide important emergency contact information.
• Present bed category summaries through reports.

Technology Used

HTML5: Creates the structure of the website.
CSS3: Designs the layout, colors and responsive pages.
Visual Studio Code: Used for writing and editing the code.

Project Information
